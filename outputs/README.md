# outputs/

Research outputs hosted on the site. Posters are listed in `content.json` (feed entries with `type: "Poster"`), which shows them in What's new and in the Posters section of Research.

Link format: `https://charleneronquillo.com/outputs/<name>/` (redirects to `<name>.pdf`)

Short links without `.pdf`: add a folder named like the file containing an `index.html` that redirects to `../<name>.pdf`.

Naming: no spaces (replace with hyphens). Paths are case-sensitive. Renaming a file breaks any link already shared.
